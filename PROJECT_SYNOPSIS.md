# Project Synopsis: DiskScope V5.1 — Disk Space Analyzer

**Project type:** Operating Systems Mini Project  
**Language:** Python 3  
**GUI:** Tkinter

## Problem Statement
Users need to identify which files and folders consume storage on a computer. DiskScope scans a selected drive or folder and shows folder sizes, largest files, and folder-level usage percentages.

## Features
- Folder Breakdown with sizes, file counts, and paths
- Files & Actions: open files, open containing folder, move and delete selected files
- Folder Usage: horizontal percentage bars for folders inside the selected location
- CSV report export
- Current location display and full-width navigation buttons

## Operating Systems Concepts
File system hierarchy, directory traversal, file metadata, storage aggregation, background threads, file operations, and exception handling.

## Safety
Scanning is read-only. Move and delete require manual selection; delete is permanent. Demonstrate actions using a test folder.
